# Website image sources

Only real documentary imagery with clear provenance may be used on the public website.

## Mandatory selection rule

A public production image must visibly show an essential human manufacturing step.

Suitable:
- shaping
- cutting
- sewing
- joining
- assembling
- soldering
- forming
- finishing
- polishing
- other direct product-making work

Not sufficient on its own:
- quality inspection
- measuring
- visual inspection
- packaging
- labelling
- standing beside machinery
- monitoring an automated process

If the visible activity would not materially contribute to the creation of the physical product, the image should not be used as a core Made by Humans manufacturing image.
